# Simple Interest Calculator

## Description

A simple calculator that calculates Simple Interest based on the Principal Amount, Rate of Interest, and Time.

## Formula

Simple Interest = (P × R × T) / 100

Where:

- P = Principal Amount
- R = Rate of Interest
- T = Time

## Example

Principal Amount = 1000

Rate of Interest = 5%

Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = 100

## Features

- Calculates simple interest
- Easy to use
- Takes principal amount as input
- Takes rate of interest as input
- Takes time as input
